# Wan の切り替えのコマの上で話し続ける試し（2026-11-23、新PC）

構想「動きの部品の作り置き＋組み合わせ」（拠点から出て拠点へ戻る 2〜3 秒の動きを、話しながら流す）の前に、
今ある物で確かめた。角度別の口の部品（約 60 枚）を Codex で作らせる前の試し。

## やったこと

- 凜のパック（`packs/rin`）の Wan の列 `home→X` と `X→home`（各 47 コマ）を 30fps でつなぎ、約 3.1 秒を話し続ける想定にした。X は think・gassho・point_r・open
- 声は design-vs-system（凜の声）の頭 3.1 秒。口の形は render.py の音量式と同じ流れ（`frame_levels`→`choose_mouth`→`smooth_mouth`）。94 コマのうち 73 コマで口が開く
- 部品は列の前半は home の、後半は X の口の部品。各コマで顔の合わせ（ECC のアフィン、render.py の `face_affine` と同じ）で写して貼る
- 貼り方を並べた: A 今のまま、B 縁の帯の平均の色を足す、C 唇の形の違う所を除いた差をぼかして場所ごとに足す、D 写す前に口の範囲の中心に届かない島を捨てる（render.py と同じ `lib.trim_islands`）

スクリプト: `mouth_on_wan.py`（書き出し）、`lag.py`（口の置き場所と Wan の顔の唇の重心の差）、`islands.py`（小島の浮き）、`facemove.py`（列の中で顔がどれだけ動くか）。

## 分かったこと

| 何 | 結果 |
|---|---|
| 口の本体の縁の色 | 縁から内側 6px の帯で、貼った色とコマの色の差 ΔE は平均 3〜7（m3 の大開きは 6〜12）。止め絵で口の周りは浮いていない。「泥棒のひげ」は出なかった（SDXL の部品のときと違い、Codex の部品は肌の色が姿勢の絵と同じため） |
| 色合わせ（B・C）と小島を捨てる（D） | 部品全体の縁（小島の縁も含む、アルファ 0.5〜0.95 の帯）の ΔE の平均は、A 4.3〜13.2、C 4.1〜12.6、D 2.9〜3.97。色合わせの効きはわずかで、A の大きさの大半は小島の縁から来ていた（point_r 13.2→3.8、think 8.5→3.3） |
| 口の置き場所 | 1 コマ間の跳びは最大 1〜2 px（1672 px の高さで）。Wan の顔の唇の重心との差の揺れは、open 1 px、think 3 px、gassho 8 px（縦）、point_r 6 px（横）。差は速さとの相関が弱い（gassho 位置と r=−0.79、速さと −0.08）ので、時間の遅れではなく、Wan が唇を少し違う所に描くずれ。全身を縮めて置けば 2〜3 px |
| 顔の合わせ | cc は最小 0.92（point_r）。0.80 を割って部品が消えるコマは無かった |
| **部品の小島** | **浮きの本当の原因はこれ**。口の部品（parts_*/m*.png）の 7 割近くに、口から離れた小島（お団子の脇の髪と背景の縁、首の左の縁）が入っている（凜 115/173、蘭 126/245）。口の差分を描かせたとき、Codex が髪の縁を少し描き直した所が差分として切り抜かれた物。止めた姿勢の絵の上では同じ絵なので見えないが、Wan のコマでは髪が動くので、元の絵の髪と背景が貼られる。小島の中の ΔE（90 パーセンタイル）は think・open で 20 台、gassho で 50〜105、point_r で 190〜230（お団子の黒と背景の白が入れ違う）。見ると、お団子の左の縁に白い楔が食い込む |
| 小島を捨てる（D） | お団子の縁の白い楔が消える。口の本体は変わらない。初版の台は捨てるのを写した後にしていて D が A と同じ絵だった（PR #120 の Codex の指摘）。写す前に直して撮り直した |

## 結論（試しの判定の材料）

- 口を合成で Wan のコマに貼る道は通る見込み。肌の色合わせは要らない。要るのは「口の部品の小島を捨てる」こと
- ユーザーの判定は「悪くない」（2026-11-23）
- 入れた直し（`face.trim_islands`、engine: wan のとき既定で有効）: 中割りへ写す口の部品から、口の範囲の中心から短い辺の 1/4 以内に来ない島を捨てる。「いちばん大きい島」は蘭の m1（髪の島の方が大きい）で口を捨てるので使えない。「口の範囲に触れる島」は、部品をその矩形の中で切るので小島も必ず触れていて、何も捨てられなかった（初版で本番の書き出しが 1 画素も変わらなかった）
- 本番の道（vm render、凜、think・point_r・gassho の往復を 1 秒の切り替えで、話しながら 7 秒）で main と比べた: 変わったのは切り替えのコマだけ（420 コマ中 260）、止めた姿勢のコマは 1 画素も変わらない。お団子の縁の白い楔が消えた
- 限界: 蘭の m2・m3・m4・m7 は髪の帯が口とつながった 1 つの島なので残る（m1・m5・m6 は直る）。直すなら部品の切り方の側
- `face.occlude`（本番で有効）だけでは小島の ΔE は半分ほど（point_r で 200 台 → 80〜100）にしかならなかった（`islands.py --occlude`）
