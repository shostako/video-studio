# 姿勢の切り替えを Wan で動かす（2026-10-30〜31、新PC）

パラパラ（姿勢の絵＋RIFE の中割り）の「切り替えのぎこちなさ」を、Wan2.2 I2V の First-Last-Frame で置き換えた調査。最終的な組み方:

- **止めて話す所**: Codex の姿勢の絵（`poses/pose_<姿勢>.png`）＋ video-mascot の正式な部品（`parts_<姿勢>/` の透過 PNG と `parts.json`）。口パクのみ版と同じ見た目
- **姿勢の切り替え**: Wan2.2 I2V-A14B Q4_K_M ＋ Lightning 4step（`WanFirstLastFrameToVideo`、始点＝前の姿勢、終点＝次の姿勢、704x1248、13 コマ）。RIFE で 4 倍にして、元の切り替えの秒（`interp.durs`、既定 0.7 秒）で再生。切り替え中も顔（目と眉）を追って口の部品を重ねる
- **下半身**: 全部 home の下半身（`lib.lock_legs`、横のずらし dx を 0 に固定）
- **書き出し**: 背景を透明にした webm（VP9 アルファ）。解説画面の側でアルファで重ねる

スクリプト: `render_wan.py`（書き出し）、`compose_layout.py`（解説画面に重ねる、大・小）、`comfyui/gen_wan14b_mascot_flf.py`（Wan の生成。ComfyUI の portable の python で回す）。

## 分かったこと

| 何 | 結果 |
|---|---|
| 1 本の時間 | 704x1248・13 コマで約 3〜4 分（RTX 5070 Laptop 8GB）。448x800・81 コマ（5 秒）で約 4 分 |
| 切り替えの長さ | 1 秒でも 2 秒でもユーザーの違和感なし |
| 足元 | 姿勢ごとに脚の幅が変わって違和感 → home の下半身に固定。`lock_legs` は腰の重なりで ±40px 横にずらすので、毎コマ通すと足元が 5px 揺れる → dx=0 にする（lib に指定を足す） |
| チカチカ | Wan の FLF は**最後の 4 コマ（VAE の最後のまとまり）で明るさが崩れる**。28 本中 27 本で 10〜13 コマ目の背景が 1 コマ目から 5 以上ずれた（背景 253→232、全体 214→199）。1 本は 12 コマ目が灰色に色抜けして、透過の判定からも外れ、人物が半透明に見えた → **ずれ始めたコマから後ろを捨て、Codex の終点の絵を置いて RIFE でつなぐ**（着地が必ず正しい絵になり、切り替え中の顔の追跡も外れなくなった）。さらに各コマを始点と終点の絵の間に色合わせ（平均とばらつき）、最後の 2 割で止まった絵へ重ねて渡す、背景を透明に。跳ねは背景 15→0.6 以下 |
| かくつき（会釈で目立った） | Wan は動きを後ろに寄せて作りがちで、最後の 4 コマを捨てると、残りの動きが終点の絵への RIFE の 1 区間に詰まって跳ぶ。コマを時刻の割合で選ぶと、前半は止まり、最後に一気に動いた → (1) **動きの量で割り付ける**（コマ間の変化を積み上げ、時間の割合＝動きの割合になる位置を出す。始まりと終わりは smoothstep）(2) その位置の**前後 2 枚を重ねる**（1 枚を選ぶと同じコマが続いて止まっては跳ぶ。両手を開くで 51 コマ中 14 コマ止まっていた）(3) RIFE を 16 倍 (4) 始まりと終わりの 15% は止まった絵と重ねる。止まるコマ 0、1 コマの変化は最大 2 前後に |
| 小さい動き（会釈） | Wan を通さず、描いた 2 枚（止まった絵そのもの、出力と同じ大きさ）の間を RIFE で直に 64 倍に補間する方がきれい。縮めた絵で補間すると、入った瞬間に柔らかくなって跳ねる |
| 腕組み | Wan に「腕を組む」と書くと手首を交差させるだけ（指が全部見える）。Codex の姿勢の絵を終点にすれば正しい腕組みになる |
| 部品を SDXL（LoRA）の inpaint で作る | 肌の色・唇の形がばらつき、Wan のコマに貼ると口の周りが楕円や弧に浮く（「泥棒のひげ」）。周波数分け・色で唇だけ切る等を試したが、どれも別の跡が残った → **部品は Codex で作る**（同じキャラが保てる） |
| 全身の絵の部品を楕円で切る | 不要だった。video-mascot の部品は元から透過の切り抜き＋置き場所の形 |
| Wan に身振りを全部任せる（I2V、始点＝終点＝立ち姿で 5 秒ずつ） | 動きは滑らかだが、口は貼るしかなく、Wan の顔に貼るとひげ。指の本数・腕組みも指示どおりにならない |
| Wan2.2 S2V（声から動画） | 20 ステップで 5 秒 35 分。日本語だと口が閉じがち。Lightning（wan2.2_t2v_lightx2v_4steps_lora_v1.1_high_noise）で 4 分になるが口・手が崩れる。8 ステップで 7.6 分、手に網目。補欠 |
| char_04a LoRA（SDXL）で始点の絵を作る | 縦長（768x1344）だと 4.5 頭身に伸びる。768x1024 なら約 3 頭身。ただし部品作りに向かない |
| 新キャラ（cand_04） | `vm init` → 6 姿勢を Codex → home の口・目 9 枚 → `vm face` は目の範囲が広すぎと出た（髪の差分）ので手で書く → `vm parts --borrow home` で 6 姿勢に写す（顔の合い 0.963〜0.999）。Codex 15 枚 |
| 姿勢の絵の無いうなずき | 前の姿勢→nod→次の姿勢 を 1 本の Wan（25 コマ）にまとめる |
| 合成の大きさ | 透過の素材は最初のコマのアルファで人物の上端・下端・中心を測ると、キャラが違っても背が揃う |

## スキルにするとき

- video-mascot の中割りの選択肢に `engine: wan` を足す（RIFE の中割りの代わりに、組ごとに Wan の FLF を作ってためる。`ib_interp` と同じく元の絵が変わったら作り直す）
- `lib.lock_legs` に横のずらしを止める指定
- Wan の色合わせと終わりぎわの重ね、切り替え中の口の追跡
- ComfyUI の起動と生成は新PC限定（Wan のモデル・Lightning の LoRA・CLIP Vision）
