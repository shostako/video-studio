## 2026-11-01 口パクのずれの直しと公開方針の記録

- 凜（B）で作った解説動画 3 本（cad-viewer・電気代・設備メンテナンス費）の最後の台詞で、会釈をやめて話させる直しをした。設備メンテナンス費で、声が出ている 277.3〜278.0 秒の間口が閉じたままだった。原因は render の声の大きさの読み位置で、`SR // FPS`（16000 Hz・60fps で 266.67→266）の歩幅により終わりで 0.69 秒早くずれていた。`lib.frame_levels` で直した（#51）。3 本とも頭から書き出し直す
- 直した範囲だけを元の webm につなぎ直す手元の道具で、ffmpeg の `filter_complex` に同じ入力を 2 つの `trim` で渡したら、後ろの区間のコマが前の区間を書き終えるまでメモリに溜まり、280 秒の動画で WSL ごと落ちた（2 回）。1 コマずつ読んで差し替える形にし、重い処理は `systemd-run --user --scope -p MemoryMax=...` の中で動かす。つなぎの間のメモリは約 2.9GB で横ばいになった
- 2026-10-31 に lab セッションでユーザーと決めた公開の方針を DECISIONS.md に、次にやることを ROADMAP.md に起こした。研究フォルダの `compose_layout.py` を手元で使っている版（`--audio`・`--full`・`CROP` の出力・`--place-only`）に差し替えた

## 2026-11-01〜02 3 つの型・パックの配布・第三者の PC で作れるか（#53〜#77）

lab のセッション（新PC）で、旧PC の確認役のセッション（Remote Control）と分担して進めた。

**解説動画の 3 つの型とパック**
- 口が閉じる件（英字・数字の語、語の間の隙間）、余白にマスコットを置く `vm layout`、画面を縮めて右に寄せる割り付けと章の見出し、ワイプの型、入口 `vm explain`（#53〜#61）
- パックの作り置き（Wan・RIFE）を WebP で持ち、判定を md5 に。Wan・RIFE の無い PC でも組み合わせるだけで書き出せる（#58〜#60、#66）。PC 決め打ちのパスを環境変数に（#62）
- パックを GitHub Releases（`packs-2026-11-01`、CC0）に置き、`vm packs`・`setup.sh` が `data/packs.json` の版を取る（#70）。旧PC で凜・蘭とも、Releases から入れたパックで 3 つの型を作れた（完成の判定）。`vm pack <名前> --new`（#74）
- 声の終わりのゴミの音（#68）、身振りの重なりの検査（#69）、門が Codex の要約の「レビュー中」のままの結果を受け付ける（#71）

**画質と速さ**
- ワイプは顔の周りだけ書き出す `vm render --crop face`。遅さの正体は `lib.matte` の numpy `min(axis=2)`（1 コマ 24 ms → cv2 で 0.8 ms）。凜の 20 秒で 106 → 39 秒、旧PC では 1.55 倍（#72）
- 白いシャツ・おでこの光が透けて暗い背景で穴に見える件: ユーザーの「囲まれた所は体として閉じる」で `config.matte.enclosed: "keep"`（opt-in）。素直に閉じると脚の間が白い板になったので、内側の 9 割以上が背景の色そのものの所だけ抜く（#73）

**第三者の PC で作れるか**
- コードの許諾を MIT に（ユーザー決定、#75）
- 新しい WSL（Ubuntu 24.04 の素の中身）で README の手順だけを流し、単位換算の Web アプリの解説動画を蘭で 1 本作った。穴 5 つ（apt update、python3-venv、壊れた venv、`/img` の NG 扱い、Playwright）を直した（#76）
- WSL を使わない Windows（Git Bash）に移植した（#77）。試験用の家（`C:\Users\shost\vs-wintest\home`）に `HOME`・`USERPROFILE` を向けて、普段の設定を汚さずに試した。穴: リンクが写しになる（→ ジャンクション）、venv が `Scripts/python.exe`、改行が CRLF（→ `.gitattributes`）、Windows の Python 3.14（→ uv で 3.12）、CP932（→ `PYTHONUTF8=1`）、Irodori の場所の埋め込みの `\U`、聞き取りの Python、フォント（→ 游ゴシックなど）
