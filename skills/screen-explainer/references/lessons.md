# 罠と決まり（2026-10-29、Excel 2 本と Web アプリ 1 本を作ったときに踏んだもの）

## Excel を撮る

- **打ち込みの途中（編集モード）は、Excel が COM の呼び出しを全部拒否する**。セルの座標は打つ前に取る。`excel_capture.py` は座標を取ってから `type` を送り、撮ってから Enter で確定する。
- **入力規則のリストは Alt+↓ で開かないことがある**。セルの右端の外側にある▼をマウスで押す（`"dropdown": true`）。
- **ウィンドウ枠の固定がある所は、セルが属する区画（`Panes(1..4)`）で座標を変換する**。いつも `Panes(1)` で変換すると、固定の外のセルの枠が固定した行・列の分だけずれる。
- **WScript の `SendKeys("%")`（Alt）で前面化を促すと、リボンのキーの札が出たまま写る**。Esc で消すか、Alt を送らない。
- **画面の座標と撮影の座標をそろえる**: `SetProcessDPIAware()` を最初に呼ぶ。呼ばないと 125 % 表示で枠が縮んでずれる。
- 元のブックは開かない。写しを開き、撮ったら保存せずに閉じる。
- PowerShell 5.1 から Excel の COM を使うと、型の変換で失敗する機体がある。Windows 側の Python と pywin32 を使う。
- WSL から Windows の Python を呼ぶときは、スクリプトと `states.json` を Windows から見える場所（`C:\Users\<you>\AppData\Local\Temp\...`）に置き、パスは `C:\...` の形で渡す。

## Web アプリを撮る

- **ページが `scroll-behavior: smooth` だと、スクロールの途中で撮れてしまう**。`web_capture.py` はスクロールを瞬時（`behavior: 'instant'`）にしている。
- 本物の端末・会話が WebSocket でつながる枠は、`block_websocket` で切ってから撮る。つないだまま撮ると、撮影で本物の会話に文字を送りうる。
- iframe の中の要素の座標は、iframe の左上を足して画面の座標にする（`frame_rects`）。
- 押してはいけないボタン（取り込み・戻す・削除・送信）は `do` に書かない。欄で Enter も送らない。

## 3D の画面（cad-viewer を撮ったとき）

- 裏のブラウザ（headless の Chromium）でも WebGL は描ける。`browser_args` に `--use-angle=swiftshader` と `--enable-unsafe-swiftshader` を渡す（GPU の無い機体でも同じ絵になる）。
- 面をクリックする位置は、形の座標から決める。アプリの 3D の点を画面の座標に変える関数（cad-viewer なら `window.__cadProject(x, y, z)`）を hooks から呼ぶ。形の座標は、CAD のファイルを OCP などで読んで面ごとの中心と種類（円筒・平面）を出して選ぶ。
- 開いたファイルの計測や注記を、アプリが自動で保存して次に開いたときに出すことがある。撮影用にデータの置き場を分け（cad-viewer は `CAD_VIEWER_DATA_DIR`）、撮る前に消す。
- サンプルの形は、出所と使い方の条件が言える物を使う（cad-viewer では Open CASCADE の bearing.iges と ConceptFORGE の spool.iges）。単位の見出しが実寸と合わない物は、写しの見出しを直して使う。

- 回す・寄る動きは、ドラッグを 30 ほどに刻んで 1 刻みごとに撮る（`drag_film`）。刻むたびに描き終わりを待ち（requestAnimationFrame を 2 回）、撮る。swiftshader でも 1 刻み 0.1〜0.2 秒で撮れ、続くコマの差がそろう（引っかかり無し）。連番は覚えておかずに 1 枚ずつ読む（3 本で 90 枚近くあり、覚えると数百 MB になる）。

## 声

- 語ごとの長さ（`word_timing.py`）で溜めを見る。台本との一致が高くても、「電気」が「でんーき」と伸びる行がある。伸びた語の前で文が切れていないか（読点の置き方）を見直す。
- 「型締力」は「かたじめりょく」。Irodori も Gemini も別の読みにしやすい。この語が入る行は `say` で仮名に開く（「型内圧」は「かたないあつ」）。
- `say`（ふりがな）は読み違えた行にだけ書く。全行に書くと抑揚が崩れる。
- Gemini TTS は指示文を本文と一緒に読み上げる（`system_instruction` が使えない）。声の指示は Irodori の `caption` で書く。

## ワイプ

- 口の形ごとに別の絵を丸ごと差し替えると、頭が少しずつずれてカクカク動いて見える。閉じた顔の 1 枚を固定し、口（顎）の範囲だけを楕円でぼかして貼る（`wipe_faces.py`）。
- カーソルについて回る小さなマスコットは画面の邪魔になる。ワイプは右下の 1 つにして、強調の枠・カーソル・キーの札に重なる場面だけ別の角へ逃がす（`compose.py` が場面ごとに選ぶ。決めたいときは `add(..., corner="TL")`）。

## 再生と送る

- 30MB を超える動画は Remote Control でスマホに送れない。`-crf 29` でスマホ用を作る（4 分半で約 21MB）。
- VLC でループ再生すると、ループの頭で窓を動画の大きさに広げ直す。`--no-qt-video-autoresize` を付ける。
- WSL で `pkill -f` / `pgrep -f` に動画の名前を渡すと、そのコマンド自身のシェルも当たって自分を殺す。PID を確かめてから止める。
