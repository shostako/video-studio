# パラパラ（/img の差分）で素材を作る

無料（ChatGPT のサブスク枠）で、どのコマで何をするかを完全に決められる。なめらかな動き（髪のなびき、水・雲・炎）は出せない。向くのは、打鍵・まばたき・表情の切り替え、状態の移り変わり（昼→夜、晴れ→雨、点灯）。

## 1. 元の絵（base）

/img スキルで作る（`img` スキルが無ければ、同じ引数の `~/.claude/skills/video-mascot/scripts/img/img.sh -p <指示文> -o <出力パス>`）。キャラを揃えるときは、既存の絵を `-r` で渡す。
- 構図は最初から決め打ちする（重ね表示の置き場所を空けておく。例: 右に余白）
- 脚・手が崩れやすい姿勢（床に座る等）を避ける。椅子と机のような、形が決まる姿勢にする

## 2. 差分（variants）

元の絵を `-r` に渡し、変える所だけを指示する。決まり文句:

```
添付画像を編集して。変えるのは〈手だけ／目だけ／表情だけ／腕と手と表情だけ〉。〈どう変えるか〉。
それ以外（キャラの位置と大きさ、体の向き、脚、髪型、服、机、椅子、ノートPC、背景、カメラの位置と画角、
照明、画像の縦横サイズ）は元の画像と完全に同じに保つ。構図を描き直さず、指定した部分だけを差し替える編集にする。
漫画的な記号やエフェクト（怒りマーク、稲妻、集中線）は描かない。
```
- 記号（怒りマーク等）は絵に描かせず、重ね表示の `mark` で足す（動かせる・消せる）
- 打鍵は「手前の手を上げる」「奥の手を上げる」の2枚で足りる
- 数枚まとめて作るときは並列でよい（1枚40〜70秒）

## 3. 揃えて状態を書き出す

```bash
vs flipbook flip.json --outdir states
```
- `layers`: 部分だけ差し替える差分。`box` は差し替えてよい範囲（元の絵の座標）。手と頭のように層を分けると、組み合わせ（手×表情）が自動で全部できる
- `full`: 絵ごと差し替える差分（ポーズが大きく変わるもの）
- 出力の `align` 行で位置合わせのずれを確かめる。scale 1.00±0.01・shift 3px 以内が正常。外れたら差分を作り直す（構図ごと描き直された）
- 実例: `assets/examples/deploy_flipbook/flip.json`

## 4. 時間割と音

- scene.json の `base.timeline` で状態を並べる（scene-spec.md）。打鍵は 1秒8枚（step 0.133）
- 音は無いので `vs sfx cues.json sfx.wav` で合成し、scene.json の `audio` に入れる（打鍵・Enter・警告音・ドン 等）
- ターミナルの文字送りと打鍵音は別々に決まる。ぴったり合わせたいときは typing を使わず click を並べる
