# Veo で素材を作る

## モデル（Gemini API、2026-10 時点）

| 指定 | モデル | 料金（音付き・1秒） | 8秒 | 出さないもの（--neg） | 向き |
|---|---|---|---|---|---|
| `lite`（既定） | veo-3.1-lite-generate-preview | $0.05（720p）/ $0.08（1080p） | $0.40 | 使えない | 試し撮り。気に入る1本が出ることもある |
| `fast` | veo-3.1-fast-generate-preview | $0.10 / $0.12 | $0.80 | 使える | lite で余計なものが消えないとき、仕上げ |
| `standard` | veo-3.1-generate-preview | $0.40 | $3.20 | 使える | 未検証。ユーザーに断ってから |

- 1本は 4 / 6 / 8 秒。長い場面は sequence でつなぐ
- 無料枠は無い。課金は成功した分だけ。安全フィルタ（特に音声）で止められた回は課金されない
- **1日あたりの回数に上限がある**（モデルごと。2026-10-12 実測で lite は約17回、fast は約22回で 429。止められた回も数に入るらしい）。超えると `vs veo` は終了コード 7。枠は太平洋時間の0時（日本時間16〜17時）に戻る。急ぐなら別のモデル（fast→standard）は別枠で通った
- 請求先は watermark-remover の Gemini API キーのプロジェクト（AI Pro の月 $10 クレジットを当てる運用）
- 1本ずつ費用を伝える。何本も作る前に一言断る

## 指示文（英語で書き、セリフだけ日本語で引用）

```
<被写体と最初の状態>. <起きること1>, says in Japanese, "<セリフ1>". <起きること2>... Finally <最後の状態>.
Static camera, locked-off shot, <背景>, soft studio lighting.
Keep the character design, proportions, outfit and look exactly as in the first frame.
<キャラなら> Her eyes stay dry the whole time (no tears).
No text, letters, captions, speech bubbles or written symbols appear anywhere in the video; the dialogue is spoken only.
Sound: <効果音を順に>. <声の印象>, speaking Japanese.
```
- 「文字を出さない」行は必須（無いと頭の横に意味のない日本語風の文字を描くことがある）
- キャラ物は「涙なし」も入れる（頼んでない涙を足すことがある）
- 重ね表示の位置を固定したいので、カメラは止める（Static camera）
- 8秒に出来事を詰めすぎるとセリフが早口になる。最後の1秒は「そのまま動かない」くらいの余白を書く
- fast / standard なら `--neg "tears, crying, text, subtitles, watermark, objects breaking, morphing"` も付ける
- 実例: `assets/examples/deploy_veo/prompt.txt`

## 実行

```bash
vs veo --prompt-file prompt.txt --first start.png --model lite --name Monday_Deploy
```
- `--first` の絵は縦横比が違えば白（端の色）を足して 16:9 にする。元の絵の位置は作業フォルダ（指示文と同じ所）の `*_pad.json`
- `--last` で最後の絵も指定できるが、終わりの0.2〜0.3秒でそこへ無理に寄せて崩れる疑いがある（未確認）。まずは付けずに作り、終わりは `cut` で止める

## よく出る失敗と直し方

| 出たもの | 対処 |
|---|---|
| 終わりの0.2〜0.3秒で手・頭がぶれる、物が潰れる | scene.json の `base.cut` で直前のコマで止める（fixes.md） |
| 頼んでない涙、勝手な文字 | 指示文の必須行を確かめて引き直し（fast なら --neg も） |
| 口が小さくすぼまったコマに、閉じた口の線が重なって残る | `vs line_fix`（fixes.md） |
| セリフが台本と違う（「通るの」など） | 不要な音だけ `vs audio_cut`。吹き出しは聞こえたとおりに |
| 語尾や間に余計な音を足す（「〜ね」「〜と」「〜なの」「ふーん」「開けては」） | 1つずつ `vs audio_cut` で消し、`vs ear --repeat` で確かめる（射出成形の回は9か所消した）。指示文に「余計な語を足すな」と書いたら音声のフィルタで止められたので、指示文では防がない |
| 漢字を読み違える（2026-10-12 の解説で: 外周→そうしゅう、圧縮代→あっしゅくだい、型締力→かせんりょく、縮む→しぼむ、充填→じゅうふつ、金型→きねがた） | 専門用語と読みが割れる漢字は、指示文のセリフの中で**ひらがなで書く**（「がいしゅう」「あっしゅくしろ」「かたじめりょく」「ちぢむ」）。ひらがなにした語は正しく読んだ。書き出したら `kana.py`（Gemini にひらがなだけで書き起こさせる。下の「読みを確かめる」）で全カットの読みを見る。Whisper や普通の書き起こしは文脈で漢字を当てるので読み違いを見逃す |
| 1語だけ読み違えて、別の版では正しい | 同じ姿勢の所（両手を合わせて止まっている間など）で2本を前後につなぐ。0.25秒重ねて溶かすと顔の向きの跳びが目立たない（ffmpeg の xfade と acrossfade）。読み違いが文の切れ目の前後に分かれていれば、声もそれぞれの版のままで口と合う |
| ウインクが「片目を閉じたまま」になる | 「笑って、片目を一瞬閉じて、すぐ開ける。最後の1秒は両目を開けて笑う」と順番を書き、2本頼んで良い方を選ぶ（1本は閉じたまま、1本は狙いどおりだった） |
| 音声の安全フィルタで止められる（課金なし、終了コード 4） | 指示文の言い回しを変える。通った例: 「cries」→「shouts」、Sound から「soft sleepy breathing」を外し「mumbles drowsily」→「says sleepily」（寝息・うめき・泣き声など、体から出る音の描写が引っかかりやすい）。**日本語のセリフの動詞でも止められる**: 「押さえたまま」「押し込んで」「流し込む」「突き出したら」→「そのまま」「詰めて」「すばやく詰める」「取り出せば」で通った。動作の説明の「like injecting」（注射と取られる）も外すと通った。止められたら、セリフ→動作の説明→決まり文句の順に一つずつ変えて原因を絞る（止められた回は無料） |

## 時刻を拾う

```bash
vs analyze clip.mp4 --ask "grab_head=両手で頭を抱え始める時刻" --ask "point=画面を指さし始める時刻" --out events.json
```
- セリフは Gemini の書き起こし（一字一句・時刻つき）。動きの時刻は Gemini が 0.5秒単位くらいでずれる
- 光った瞬間は `flash`（コマの赤み）が正確。ターミナルのエラー表示などはこちらに合わせる
- 効果音（通知音・チャイムなど）の時刻は、音を図にして見るのが確実: `ffmpeg -v error -y -i clip.mp4 -lavfi "showspectrumpic=s=1600x500:legend=1:scale=log:fscale=lin:stop=8000" spec.png` を Read。チャイムは高い所に横線（倍音の筋）が並んで伸び始める点、物音は縦の線。Gemini の答え（0.5秒単位）をこれで詰める
- セリフの一語が割れたら（「よっし」「よした」「よしっ」など）、その部分だけ切って `vs ear clip.mp4 --start 5.0 --dur 2.3 --repeat 3` で多数決を取る。全体を通すより短く切った方が答えがそろう。言葉にならない声（息を呑む音）は「はっ」のように聞こえたままの擬音を吹き出しにするか、記号（exclaim）だけにする
- 下書きの時刻は、`vs frames` でその前後をコマ送りで見て確かめてから scene.json に入れる
