# アクセントの書き方と `vs accent`

## 期待する高低の列（用語辞書 `data/terms.yaml` もこの書き方。references/terms.md）

- 語の **1モーラに1文字**。`L`＝低、`H`＝高。`低`・`高` で書いてもよい（読むときに `L`/`H` に直す）。空白・`-`・`・` は無視する
- モーラの数え方: 「きゃ」は1、「っ」「ん」「ー」も1
- **語の中だけ**を書く。後ろの助詞の高さは入れない
- 例: 薄い板（うすいいた）＝ `LHHHL`、箸（はし）＝ `HL`、橋＝ `LH`、端＝ `LH`

アクセント型の数字 k（辞書でよく見る書き方）とは `accent.accent_from_type(モーラ数, k)` で行き来できる:

| k | 名前 | 4モーラの例 |
|---|---|---|
| 0 | 平板 | `LHHH` |
| 1 | 頭高 | `HLLL` |
| 2〜n-1 | 中高 | k＝2 なら `LHLL` |
| n | 尾高 | `LHHH`（語の中だけでは平板と同じ。違いは助詞が下がるか） |

## `vs accent`

```bash
vs accent 声.wav 語.json [--thresh 1.5] [--json 結果.json]
```

語.json:
```json
[{"word": "薄い板", "start": 0.10, "end": 0.62, "accent": "LHHHL"},
 {"word": "語B", "start": 0.80, "end": 1.20, "type": 0, "morae": 4}]
```
時刻は Whisper の語の時刻（`research/2026-10-15-tts/acc_words.py`）から取る。モーラの境目が分かるなら `"bounds": [境目 n+1 個]` で渡す（無ければ語の時刻を等分）。

出るもの（語ごと）:
- `score`: 声の出ているモーラの隣どうしで、上がる・下がる・平ら（差 ±1.5 半音で分ける）が期待と合う割合
- `drop_ok`: 下がり目（何モーラ目の後で下がるか）が期待と同じか。頭高と平板の取り違えは `score` では 0.67 ほど残るので、型の取り違えはこちらで見る
- `pitches`: モーラごとの高さ（声全体の中央値を 0 とした半音）。無声化したモーラ（「うすい」の「す」など）は空で、比べるときは飛ばす

## 分かっていないこと（手元待ち）

- 本物の声で、点数が耳の判定と合うか。`--thresh` の 1.5 半音は仮の値
- 語の時刻の等分でモーラ位置がどれだけずれるか（長音・撥音は短く、語頭は長くなりがち）
