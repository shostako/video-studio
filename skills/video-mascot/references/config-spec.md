# config.json（作業フォルダの設定）

```json
{
 "name": "icm-explainer", "fps": 30, "pad": 100, "home": "home", "seed": 5,
 "mascot": {"description": "a glossy resin chibi figurine girl with ... (英語。絵を描かせる時の『同じキャラ』の説明)"},
 "poses": {"home": {"desc": "hands lightly clasped in front of her waist, facing the camera almost straight on"},
           "point": {"desc": "her left arm extended toward the viewer's right with an open palm, presenting", "refs": ["gassho"]}},
 "pairs": [["home", "point"]],
 "face": {"mouth_roi": [450, 575, 600, 680], "eye_roi": [370, 500, 640, 600]},
 "floor": {"clean": true, "y0": 1180},
 "anchor": {"mode": "boot"},
 "events": [{"line": 1, "kw": "そこで", "fallback": 0.65, "pose": "point"}],
 "voice": {"caption": "...", "seed": 2024, "ref": "voice/ref.wav", "gap": 0.5, "end": 69.0,
           "candidates": ["説明文1", "説明文2"], "test_lines": [0, 3],
           "lines": [{"text": "台本どおりの文", "say": "合成に渡す文（読みを直した文）", "start": 0.0}]}
}
```

| 項目 | 意味 |
|---|---|
| `fps` | 出力のコマ数。既定30 |
| `pad` | 絵の左右に足す白い余白（画素、絵の幅 941 に対して）。体を動かしたとき指先が切れないための余裕。既定100 |
| `out_height` | 出力の高さ（既定1280）。幅は絵の縦横比と pad から決まる |
| `home` | 基本の姿勢の名前（既定は poses の最初）。軸足・口と目の範囲の基準 |
| `mascot.description` | `vm poses` が絵を描かせる時の、キャラの英語の説明。服・髪・目・台座など、同じに保ちたい特徴を書く |
| `mascot.pronoun` | 描かせる文の代名詞 `she`（既定）・`he`・`it`・`they`。中割りの指示の "Her face" がこれの所有格になる。`vm init --pronoun` が姿勢の desc もこれで書く |
| `poses.<名前>.desc` | その姿勢の英語の説明（`vm poses` が絵と中割りの指示に使う） |
| `poses.<名前>.refs` | 絵を描く時に一緒に参照させる別の姿勢（顔・服をそろえるため） |
| `poses.<名前>.scale` | その姿勢の大きさの倍率を固定する（opt-in）。書かない姿勢は今まで通り背の高さで `home` に揃える。伸び・お辞儀・屈むなど背が変わるのが正しい姿勢に `1.0` を書く（揃えると伸びが縮み、お辞儀が大きくなる）。`anchor.mode: manual` では `anchor.scales` が先。書いた姿勢は `vm views` で背を比べず、`vm face --write` は範囲を `poses.<名前>.face` に書く（顔が home から動くため）。足すポーズの一覧は `docs/mascot-poses-spec.md` |
| `poses.<名前>.expect_height` | 背の比（home=1）の想定範囲 `[下限, 上限]`（opt-in）。`vm views` が範囲の外を「※背の比が想定…の外」と知らせる（お辞儀が浅いまま描かれたのを拾う）。書かない姿勢は今まで通り（`scale` があれば比べず、無ければ ±3%）。`vm init --extras` はお辞儀 `[0.85, 0.96]`・伸び `[1.03, 1.6]`・屈む `[0.5, 0.88]`・軽い屈伸 `[0.9, 0.985]` を書く |
| `pairs` | 中割りを作る姿勢の組。`[a, b]` で `ib/ib_a_b_1..5.png`。行き来のどちらの向きにも使う |
| `face.mouth_roi` / `face.eye_roi` | home の絵で測った口・目の範囲 `[x0, y0, x1, y1]`（口は差分の外側、目は両目を含む）。`vm grid` で読む |
| `floor.clean` | 足元の台座・靴の反射を消し、接地の影を足す（台座つきの絵向け）。`y0` は足元の処理を始める高さ（既定は絵の高さの70.5%） |
| `anchor.mode` | `boot`: 向かって左の黒い靴を軸足にして全部の絵でそろえる（既定）。`manual`: `points` に姿勢ごとの `[x, y]`（と `scales`）を書く。`none`: そろえない。`feet`（opt-in）: 色に依らない足元。背景の白と違う所の一番下と、その上の背の 4% の帯の左右の端の真ん中を軸足にし、背の高さも前景の上端から測る。靴が黒くないキャラや、紺のズボンの裾を靴と取り違えるキャラ用（`vm init` は黒い靴が足元の線に無ければこれを選ぶ。`boot` で外れた姿勢は `vm render` と `vm views` が知らせる） |
| `inbetween_fps` | 中割り5枚を見せる速さ（既定15 = 0.33秒） |
| `inbetween_prompt` | 中割りの描かせ方（opt-in）。`"chain"`: 前の1枚（1枚目は始めの姿勢）だけを参照に、全体の 1/6 ずつ動かす編集として順に描く。`"percent"`: 両端を参照に「腕は 17% しか伸びていない」と数で言わせる。書かなければ今までの「1/6 の所」という言い方。`vm init` は `chain` を書く（両端を渡すと終わりの絵に引っぱられた） |
| `ib_steps` | 中割りの各枚の様子（opt-in）。`{"a>b": ["1枚目の様子", "2枚目の様子", ...]}`（英語）。描かせる文の終わりに「In this frame: …」として足す。数が中割りの枚数と違えば割合の近いものを使う。書かない組は今まで通り。`vm init` は `turn_l>present_l`・`turn_r>present_r` に腕の段階（組んだまま → 腰の高さで持ち上がる → 胸の高さ → 伸びかけ → ほぼ伸び切る）を書く（chain でも1枚目から腕が伸び切ったため）。`--gestures` なら `home>point_l`・`home>point_r`（1〜3枚目は「まだ伸ばさない」）、`--extras a` なら `home>bow`（4〜20 度の浅い刻み）・`home>stretch`（体の横から上げ、顔の前を通さない）も書く |
| `inbetween_div` | 姿勢の間を何等分するか（既定6 → 中割り5枚 `ib_<a>_<b>_<k>.png`）。12 にすると中割り11枚 `ib_<a>_<b>_<k>_12.png`。既存の5枚を偶数番（2k）に写せば、`vm poses inbetweens` は奇数番だけを「両隣のちょうど中間」として描く |
| `mouth_scale` | 口の開きの全体の倍率（既定1.0）。`--mouth-scale` でも指定できる |
| `lipsync` | 口パクの母音の決め方。`"amp"`（既定。聞き取りの語を音の数で等分）か `"mora"`（下の「口パク: mora」）。`vm render --lipsync mora` でも指定できる |
| `mora` | `lipsync: "mora"` の細かい設定（省略可）: `pause_weight`（句読点の息つぎを何モーラ分の長さにするか、既定2.0）、`close_frac`（両唇音の頭で口を閉じる割合、既定0.3）、`min_close`（閉じる最短の秒、既定0.067＝30fps の2コマ）、`trim`（行の頭と終わりの無音を声の大きさで削ってから割り付ける、既定 true） |
| `idle` | `false` で、二次運動を使わないときの息づかい（足元を中心に ±0.4% の伸び縮みと上下 ±2px が 3.6 秒周期、左右 ±1.5px が 5.3 秒周期、声の大きさで最大 2.5px の持ち上がり）を止める（opt-in。書かなければ今までどおり）。止まっている間に体が微妙にふわふわするのはこれ。`motion` を使うときは効かない（`motion` の各項目で止める） |
| `mouth_prompt` | `"jaw"` で、口7形の差分を描かせる文に「口の開きに合わせて下あごが下がり、あごの線と頬の下も動く。首・襟はそのまま」を足す（opt-in）。今までの文は「口だけを変える」なので、あごの輪郭が動かない。使うときは、口の部品を切り抜く範囲 `face.jaw_roi` を別に書き、頬からあごの下まで取る（例: 口の範囲の左右を頬の外まで、下をあごの先より 50px ほど下まで）。`face.mouth_roi` は二次運動の首の位置などにも使うので広げない。`jaw_roi` が無ければ口の部品は今までどおり `mouth_roi` で切る。顔の範囲を手で書いた姿勢（`poses.<名前>.face`、斜め・横など）は `jaw_roi` も姿勢ごとに書く（書かないと口の範囲で切り、`vm parts` が知らせる） |
| `face.occlude` | `true` で、中割りに口・目の部品を移すとき、顔の前に来た手（元の姿勢の絵と大きく違い、部品の範囲の外まで続く所）の上には貼らない（opt-in）。`vm parts --borrow` はいつもこの処理をする |
| `motion` | 二次運動（省略時は使わない＝今までどおり）。`true`（か `{}`）で全部既定、辞書で項目ごとに上書き。`vm render --motion on|off` でも切り替えられる。下の「二次運動」 |

**倍の細かさ**（2026-10-14、cad-viewer の解説動画で使用）: `"fps": 60, "inbetween_div": 12, "inbetween_fps": 30`。中割り11枚を0.37秒で見せ、口の形は30fpsの1コマ（2コマ）以下の揺れを消し、まばたきは段の間を溶かして十数段で閉じる。描き足した中割りは「両隣の中間」と指示しても順番を外す枚が出る（1枚目がいきなり腕を組み切る等）ので、`ib` を姿勢の行ごとに並べて見て、外れた枚は腕の位置を具体的に書いて描き直す。

## events（姿勢の切り替え）

上から順に、直前の姿勢から `pose` へ移る。**切り替えが終わる時刻**（ `line` + `kw`/`word` の場合）か、**始まる時刻**（それ以外）を指定する。

| 書き方 | 意味 |
|---|---|
| `{"line": 3, "kw": "ばねが", "pose": "gassho"}` | 行3で、声の中の「ばねが」（ひらがな、小さい「ゃゅょ」を含む語は不可）の直前に切り替えが終わる |
| `{"line": 3, "word": ["しゃ"], "pose": "open"}` | 行3で、聞き取りの語（ひらがな）が一致する最初の語の直前に終わる。小さい「ゃゅょ」を含むとき・Whisper が漢字を取り違えるときはこちら |
| `{"line_start": 5, "offset": -0.4, "pose": "point"}` | 行5の頭の0.4秒前に始まる |
| `{"line_end": 8, "offset": 0.05, "pose": "home"}` | 行8の終わりの0.05秒後に始まる |
| `{"at": 12.3, "pose": "arms"}` | 12.3秒に始まる |

- `fallback`（0〜1）: 声から見つからなかったとき、行の中のこの割合の位置とみなす（標準エラーに「推定」と出る）。
- `offset`: ± 秒で微調整する。
- pairs にない組（a→b）は、中割りなしで切り替わる。必要なら間に別の姿勢を挟む（例: open→home→arms）。

## 口パク: mora（opt-in）

`"lipsync": "mora"` にすると、口の母音を聞き取り（Whisper）ではなく**台本のかな**から決める。

1. 行ごとのかな台本: `voice.lines[].kana`（ひらがな・カタカナ・句読点）。無ければ `say`（無ければ `text`）を pykakasi でかなにしたもの。英字・数字は読まれないので、混じる行は `kana` を書く（例: 「ICM」→「あいしーえむ」）。漢字の読みを pykakasi が取り違える行も `kana` で直す。
2. 行の声の範囲: `voice/timing.json` の行の開始〜終了から、声が小さい頭と終わりを削る（`mora.trim`）。
3. その範囲をモーラの数で等分する。拗音（きゃ）は1モーラ、「っ」「ん」「ー」も1モーラ。句読点は `pause_weight` モーラ分の息つぎ（口を閉じる）。
4. 口を閉じる所: 「っ」、息つぎ、両唇音（ま・ば・ぱ行）の頭（`close_frac`）、両唇音の前の「ん」（「さんぽ」）。
5. 開きの大きさは今までどおり声の大きさで決める（`choose_mouth`）。声が小さいコマは閉じる。

`events`（姿勢の切り替え）は今までどおり聞き取りの時刻を使う。既定（`amp`）の動きは変わらない。

## voice

- `lines[].text` は字幕・一致の判定に使う台本、`say` は合成に渡す文（読みが割れる語だけひらがなにする）。`start` を書くと、その秒に行を置く（主動画の流れに合わせたいとき）。省略すると前の行の後ろに `gap` 秒あけて続ける。
- `ref` を書くと全行をその声で読む。省略すると、最初に作った行が残りの手本になる。
- `end`: 全体の長さ（省略時は最後の行の終わり＋0.6秒）。主動画の長さに合わせたいとき書く。
- 説明文（`caption`）は声の人物像と話し方を書く（例: 余裕のある大人の女性。艶のある低めの声。…てきぱきと早めに説明している。クリアな音質）。「テンポよく」「てきぱき」で速さを、「近い距離感」で距離感を、絵文字（台詞の語尾に 😏 など）で口調を足せるが、絵文字は暴れやすい。

## 二次運動: motion（opt-in）

`"motion": true`（か `vm render --motion on`）で、体の小さな動きを足す。書かなければ今までどおり（正弦の息づかいと、2.6〜4.6 秒の一様な間隔のまばたき）。

```json
"motion": {
  "breath": {"period": 3.6, "jitter": 0.12, "inhale": 0.4, "scale": 0.004, "lift": 2.0},
  "body":   {"sway": 1.5, "period": 5.3},
  "head":   {"roll": 0.8, "period": 4.1, "nod": 2.0, "neck": 0.6, "radius": 0.9},
  "blink":  {"mean": 3.4, "spread": 0.35, "min": 1.6, "max": 7.0, "double": 0.15, "on_switch": true},
  "switch": {"ease": "in_out", "anticipate": 0.15, "anticipate_px": 5, "overshoot_px": 4, "settle": 0.45}
}
```

値は上が既定。書いた項目だけ上書きされ、項目を `false` にするとその動きだけ止まる（例: `"motion": {"head": false}`。`"blink": false` はまばたきをしない）。知らない項目名はエラーで止まる。画素は姿勢の絵の画素（`out_height` に縮める前）。

| 項目 | 動き |
|---|---|
| `breath` | 呼吸。周期 `period` 秒が ±`jitter` の割合でゆっくりゆらぐ。1回のうち `inhale` の割合で吸い、残りでゆっくり吐く。足元を中心に `scale` の割合で伸び縮みし、`lift` 画素持ち上がる |
| `body` | 体の左右の揺れ（`sway` 画素）。割り切れない周波数の正弦を重ねたゆらぎで、同じ動きをくり返さない |
| `head` | 首から上だけを傾ける（`roll` 度）。声の出だしで `nod` 画素うなずく。首の位置は `face.mouth_roi`・`eye_roi` から見積もる（口の下端から「目→口」の距離の `neck` 倍下、頭の半幅は目の範囲の幅の `radius` 倍）。首より下（肩・腕）は動かさない |
| `blink` | まばたきの間隔を対数正規でゆらがせる（中央値 `mean` 秒、ばらつき `spread`、`min`〜`max` 秒に切る）。`double` の割合で2回続け、`on_switch` なら姿勢の切り替えの頭でもまばたく |
| `switch` | 姿勢の切り替え。中割りを何枚目まで進めるかを `ease`（`linear`・`in`・`out`・`in_out`・`sine`）で決める（長さは今までどおり）。切り替えの `anticipate` 秒前から `anticipate_px` 画素沈み（予備動作）、終わってから `settle` 秒、上へ `overshoot_px` 画素行き過ぎて戻る（オーバーシュート） |

ゆらぎは `seed` で決まる（同じ config なら毎回同じ動き）。まず `vm render <作業フォルダ> --motion on --mode white --from 0 --to 10` で今までの動きと見比べる。首の位置がずれて肩が引っぱられるときは `head.neck` を小さく、頭の端が残るときは `head.radius` を大きくする。

## 向きと視線（opt-in）

顔を横に向ける・体ごと斜めや横を向く・視線を動かす。絵の描き方と名前の決まりは `docs/mascot-views-spec.md`（リポの docs）。下のどれも、書かなければ今までどおり。

```json
"poses": {
  "turn_l": {"desc": "...", "refs": ["home"], "yaw": -40,
             "face": {"mouth_roi": [400, 575, 540, 680], "eye_roi": [330, 500, 590, 600]}, "anchor": [430, 1250]},
  "back":   {"desc": "...", "yaw": 180, "face": false}
},
"transition": {"mode": "fade", "dur": 0.25, "squash": 0.06},
"events": [{"line": 2, "kw": "こちら", "pose": "turn_l", "via": "turn"}],
"gaze": {"lead": 0.15, "hold": 1.0, "events": [{"line": 3, "kw": "ここ", "look": "l", "hold": 1.2}, {"at": 20.0, "look": "u", "until": 21.5}]}
```

| 項目 | 意味 |
|---|---|
| `poses.<名前>.yaw` | 体の向き（度。画面の左が負、正面 0、真横 ±90、後ろ 180）。目安でよい |
| `poses.<名前>.head_yaw` | 顔の向き（無ければ `yaw`）。視線の部品の選び方と、視線の先回りに使う |
| `poses.<名前>.face` | その姿勢で測った口と目の範囲（`face` と同じ書き方）。斜め・横の顔は `home` からの自動の写しが合わないので書く。`false` は顔が見えない姿勢（後ろ向き）: 口・目・視線の部品を作らず、貼らない |
| `poses.<名前>.anchor` | その姿勢の足元の基準点 `[x, y]`。`anchor.mode` が `boot` でも、書いた姿勢はこちらを使う（靴で揃わない姿勢、斜めで立ち位置が横にずれた姿勢）。`manual` で `points` に無い姿勢にも使う。端の姿勢に書いた組の中割りは、靴を測らず両端の anchor の間で補う。両足の真ん中を `home` に揃える候補は `vm views <作業フォルダ>` が出す |
| `transition` | 中割りの無い組の切り替えのつなぎ。`mode`: `cut`（一瞬。`kw` / `word` では語の 0.04 秒前に切り替える。書かない時は中割りの長さだけ早く切り替わる）・`fade`（`dur` 秒で溶かす）・`turn`（溶かしながら、途中で横に最大 `squash` の割合だけ縮めて回ったように見せる）。中割りがある組は今までどおり中割り |
| `events[].via` | その切り替えだけのつなぎ（`cut`・`fade`・`turn`）。中割りがある組でも `via` が優先。`transition` が無ければ長さと縮みは上の既定 |
| `gaze` | 視線を使う。`vm poses parts` が視線の部品も描くようになる（顔が正面の姿勢は `g_l` `g_r` `g_u`、斜めは `g_c` `g_u`、横・後ろは無し） |
| `gaze.events` | 黒目を動かす所。`look`: `c`（見る人）・`l`（画面の左）・`r`（画面の右）・`u`（上）。開始は `events` と同じ書き方（`kw` / `word` はその語の声の時刻から。`offset` はどの書き方にも足す。`at` にも）。終わりは `until`（秒）か開始から `hold` 秒 |
| `gaze.lead` | 顔の向き（`head_yaw`）が変わる切り替えの、この秒数前から切り替えの終わりまで、目が先に新しい向きへ動く（`0` で切る）。`gaze.events` の指定が優先 |

- `kw` / `word` の切り替えは「その語の直前に終わる」ので、つなぎが `fade`・`turn` の時は中割りの長さの代わりに `dur` を引いて始める。`cut`（`via` でも `transition.mode` でも）は長さ 0 として語の 0.04 秒前に切り替え、二次運動の予備動作・オーバーシュートと視線の先回りも長さ 0 で計る。
- 視線の部品が無い姿勢では、目は元の絵のまま。まばたきの間は視線の部品を貼らない。斜めの顔で `l`（向いている側）を指定すると元の目（もうそちらを見ている）、反対側や `c` は `g_c`（見る人の方へ戻す）。
- 二次運動（`motion`）とは両立する。首の傾きの中心は、その姿勢の `face` から見積もる。溶かしている間は両方の絵をそれぞれ傾けてから溶かす。
- 向きの違う姿勢（`yaw`・`head_yaw`・`face`・`anchor` のどれかを書いた姿勢）の絵が `home` と違う大きさだと止まる。

## 中割りのコマ補間: interp（opt-in）

描いた絵（端の姿勢と中割り5枚）の間を RIFE で細かくして、切り替えを決まった秒とイージングで出す。描く枚数を増やさずに動きを滑らかにする。書かなければ今までどおり（中割り5枚を 15fps で出す）。`vm render --interp rife|off` で上書きできる。

```json
"interp": {"dur": 0.6, "durs": {"gap>gassho": 1.2}}
```

| 項目 | 既定 | 中身 |
|---|---|---|
| `mult` | 8 | 描いた絵の間を何倍に細かくするか（6等分なら 47 枚の列） |
| `dur` | 0.6 | 中割りのある組の切り替えの秒 |
| `ease` | `in_out` | 何枚目を出すかのイージング（`linear`・`in`・`out`・`in_out`・`sine`） |
| `durs` | `{}` | 組ごとの秒 `{"前>次": 秒}`。逆向きにも効く。金型が閉じる合掌をゆっくり見せる、など |
| `pairs` | 全部 | 補間する組 `["前>次", ...]`。書かなければ中割りのある全部の組 |
| `direct` | false | true にすると、中割りの無い組（今は `transition` の fade で溶かす組）も、端の姿勢2枚の間を直に補間する。向き（`yaw`・`head_yaw`）の同じ組だけ。`via` を書いた切り替えは `via` が優先 |
| `model` / `exe` / `tmp` | rife-v4.6 / 新PC の `C:\ComfyUI\tools` の exe / Windows の一時フォルダ | RIFE（rife-ncnn-vulkan の Windows 版を WSL から呼ぶ） |

- 作った列は `ib_interp/<前>_<次>_x<倍>_<モデル>/` にためる。元の絵か `mult`・`model` が変わったら作り直す
- 中割りの無い組は、`direct` が false なら補間しない（`transition` の fade などのまま）
- `events` の `kw`・`word` で引く長さも、その組の秒になる（切り替えの終わりが語に合う）
- RIFE は手元の GPU で動く。クラウドでは使わない（CI は純関数だけ）

### 姿勢の切り替えを Wan で動かす: engine "wan"（opt-in、新PC）

止めて話す所は今までどおり姿勢の絵と部品のまま、**姿勢の切り替えだけ**を Wan2.2 I2V の First-Last-Frame（始点＝前の姿勢の絵、終点＝次の姿勢の絵）で動かす。中割りを描かなくても、向きの同じ全部の組の切り替えが滑らかに動く（2026-10-31 のユーザーの判定「格段に良くなった、全部こうなれば満足」）。`vm render --interp wan` でも選べる。

```json
"interp": {"engine": "wan", "dur": 0.7, "wan": {"rife_pairs": ["home>nod"], "head_poses": ["look_l", "look_r"]}},
"legs_lock": {"fix_x": true}
```

| `interp.wan` の項目 | 既定 | 中身 |
|---|---|---|
| `comfy` / `url` | 新PC の `C:\ComfyUI\ComfyUI_windows_portable` / `http://127.0.0.1:8188` | ComfyUI（portable）。起動しておく（`run_nvidia_gpu.bat`）。WSL からは 127.0.0.1 に届かないので、同梱の `wanflf_comfy.py` を ComfyUI の Python で走らせて投げる |
| `width` / `height` / `length` | 704 / 1248 / 13 | Wan に渡す大きさとコマ数（4n+1）。1 本 3〜4 分（RTX 5070 Laptop 8GB） |
| `seed` | 400 | 変えると別の動きになる。動きが気に入らない組は `ib_wan/<前>__<次>/` を消して seed を変える |
| `rife_mult` | 16 | Wan のコマの間を RIFE で何倍に細かくするか |
| `cut_tol` | 5 | 背景の明るさが 1 コマ目からこれ以上ずれたコマから後ろを捨て、終点の絵へ RIFE でつなぐ（Wan の FLF は最後のまとまり＝4 コマで明るさが崩れる。28 本中 27 本。残すと戻る所で画面がチカチカする） |
| `edge` | 0.15 | 切り替えの始まりと終わりのこの割合は、止まった絵と重ねる（入った瞬間・着いた瞬間に跳ねない） |
| `blink_tol` | 0.05 | Wan が勝手に入れる瞬きのコマを捨てる（間は RIFE でつなぐ）。目のあたりが、前後の姿勢の閉じた目（`parts_<姿勢>/e2.png` を重ねた絵）に、開いた目よりこれだけよく合うコマ。首を回す切り替えでは 9 本中 8 本で振るたびに目を閉じた（描かせる文で止めても、seed を変えても入る）。`null` で捨てない |
| `rife_pairs` | `[]` | Wan を通さず、描いた 2 枚の間を RIFE で直に補間する組。会釈のように**頭が少し動くだけ**の組はこちらがきれい（Wan だと動きが後ろに詰まってかくついた） |
| `head_poses` | `[]` | 頭だけが動く姿勢（横を見る・首振り）。その組は「頭だけを回す」と描かせ、「頭を動かさない」を外す |
| `style` | `mascot.description` | 描かせる文のキャラの説明 |
| `unet_*` / `lora_*` / `clip` / `vae` / `clip_vision` | Wan2.2-I2V-A14B Q4_K_M・Lightning 4step ほか | ComfyUI の models に置いたファイル名 |

- 組 a→b ごとに作り、`ib_wan/<前>__<次>/raw/` に Wan のコマ、`n<枚数>/` に書き出しに渡す列をためる。姿勢の絵か生成に効く値が変わったら作り直す
- 列は、各コマの明るさと色味を前後の姿勢の絵の間に合わせ、**動きの量で割り付けて**前後 2 枚を重ねて作る（Wan は動きを後ろに寄せがちで、時刻の割合でコマを選ぶと止まっては跳ぶ）。口と目の部品の重ね・足元・下半身の差し替えは RIFE の中割りと同じ
- 切り替えの秒は `dur` / `durs`、何枚目を出すかは `ease`。`pairs` で Wan で動かす組を絞れる。向きの違う組（`yaw` が違う）は今までどおり
- `legs_lock` を使うなら `fix_x: true` にする（下の節）
- 頭の動きを Wan に任せない（うなずきを描かずに Wan に作らせると、首をかしげる動きになった）。頭の動きは姿勢の絵として描いてから
- 調べた中身と見本: `research/2026-10-31-wan-transition/NOTES.md`

## 頭の向きの列: head（opt-in）

首振り・横を見るなどの**頭の動き**を、描いた向きの絵の間を RIFE で直に細かくした 1 本の列の上で動かす。Wan を使わない（Wan は首を回すと振るたびに目を閉じ、目を閉じたコマを捨てると隙間で髪がにじんだ）。口・目・視線の部品は、一番近い向きの絵の部品を、隣どうしの向きの部品の置き場所の間に置くので、どの向きでも口が動く（顔の合わせ＝ECC で写すと、首が回る途中で合わせがずれて口が顔に遅れた。2026-10-31 のユーザーの判定）。

```json
"head": {"chain": ["shake_r", "look_r", "half_r", "home", "half_l", "look_l", "shake_l"],
         "events": [{"at": 38.55, "pose": "home"}, {"at": 38.95, "pose": "shake_l"}, {"at": 39.5, "pose": "shake_r"},
                    {"at": 40.05, "pose": "shake_l"}, {"at": 40.45, "pose": "home"}]}
```

| 項目 | 既定 | 中身 |
|---|---|---|
| `chain` | （要る） | 頭の向きの姿勢を一方の端から他方の端へ。体（腕・脚）は同じ姿勢で描く。隣どうしの角度の差は 6〜12 度に（大きいと RIFE でにじむ） |
| `events` | `[]` | 頭の動きの要所。開始の書き方は `events` と同じ（`at`・`kw`/`word`＋`line`・`line_start`・`line_end`、`offset`）で、その時刻にその向きにいる。要所の間は始まりと終わりを緩やかに動く。最初の要所から最後の要所までは、姿勢の時間割（`events`）より頭の列が優先 |
| `mult` | 6 | 隣どうしの向きの間を、中割りの等分（`inbetween_div`）の何倍に細かくするか |

- 列は `interp` の RIFE（`exe`・`model`、`interp` を書かなければ既定）で作り、`ib_interp/<前>_<次>_direct_x<倍>_<モデル>/` にためる
- 頭の動きは、体が `chain` の体と同じ姿勢（ふつう `home`）でいる間に置く
- 描き方: 「頭だけを回す。肩・手・足は参照のまま」。向きの間でお団子など後ろの髪が首の反対側へ移る所は、間にもう 1 段（その角度では後ろ髪が隠れて見えない絵）を足すと、RIFE のにじみが消えた。首をかしげる絵は 3 頭身だと首が縦のまま頭だけ回って見えたので使わない
- 各向きの絵には口・目の部品を作る（向きが home と違うので `--borrow` でなく、描いて `face` を書く）

## home 経由の切り替え: via_home（opt-in）

中割りの無い組 A→B を、A→home と home→B の中割りでつなぐ。身振りを home との組だけで描けば、身振りどうしの組を描かなくても、一瞬で跳ばずに切り替わる（組の数が身振りの数で済む）。書かなければ今までどおり。

```json
"via_home": true
"via_home": {"hold": 0.15}
```

| 項目 | 既定 | 中身 |
|---|---|---|
| `hold` | 0 | home に着いてから B へ動き出すまでの秒 |

- 経由するのは、A→B の中割りが無く、A と home・home と B の両方に中割りの組がある時だけ。home を含む切り替えはそのまま
- `transition`（溶かし）と `interp.direct`（直の補間）より先に効く。`events[].via` を書いた切り替えは `via` が優先
- `kw`・`word` の切り替えは、2つの切り替えと `hold` を足した長さだけ早く始め、語の直前に B に着く。`at`・`line_start`・`line_end` はその時刻に A から動き出す（B に着くのはその分あと）
- 時刻の順で前の切り替えが A に着かない時（events の順と時刻の順が食い違う時）、前の切り替えを終える前に A から動き出すことになる時、B に着く前（home→B の途中を含む）に次の切り替えが始まる時は経由しない。開始の時刻も今までどおりの長さで決める
- 2つの切り替えの長さはそれぞれの組のまま（`interp` の `dur`・`durs` も効く）。二次運動の予備動作・まばたきは2つの切り替えのそれぞれに付く

## 下半身の差し替え: legs_lock（opt-in）

姿勢ごとに描いた絵は、脚の開き・靴の位置が少しずつ違うことがある（参照にした home を描き直した後に描いた組と、前に描いた組で立ち方が分かれる、など）。切り替えのたびに足元が動いて見えるのを止めるため、正面の姿勢と中割りの腰から下を、1つの姿勢の下半身に差し替える。書かなければ今までどおり。

```json
"legs_lock": {"from": "home", "cut": 0.38, "feather": 0.03, "hand_zone": 0.45}
```

| 項目 | 意味 |
|---|---|
| `from` | 下半身を写す元の姿勢（既定 `home`）。立ち方を揃えたい絵を選ぶ。`from` の絵の腰の前の手（肌の色）は写さない |
| `poses` | 差し替える姿勢（既定は正面の姿勢＝ `yaw` が無いか 0。`from` は除く）。中割りは両端とも差し替える姿勢（か `from`）の時だけ差し替える |
| `cut` | 切れ目の高さ。`from` の絵の背の高さに対する割合で、足元から測る（既定 0.38 ＝腰の少し下、股の分かれ目より上）。上着の裾より下にする。下げすぎて帯が股の分かれ目にかかると、内股の輪郭が二重になる |
| `feather` | 切れ目の上で溶かす帯の高さ（背の割合、既定 0.03）。帯の中は、腰の左右の端と股の隙間を行ごとに伸び縮みさせてから混ぜるので、腰の幅が違っても輪郭は二重にならない |
| `hand_zone` | 切れ目から足元までのうち、元の絵の手（肌の色）と、腰・脚の外にある腕・手を残す上の割合（既定 0.45）。腿に置いた手や体の横に下ろした手が消えないように。足首の肌は `from` の方 |
| `fix_x` | `from` を横にずらして腰に合わせるのをやめる（既定 false）。Wan の切り替え（`interp.engine: "wan"`）のように毎コマ差し替える時は true にする。ずらしの量がコマごとに変わり、足元が数 px 揺れる（実物で 5px） |

- 差し替えは書き出しの時だけで、`poses/` と `ib/` の絵は書き換えない。足元の点と大きさ（`scale`・背で揃える倍率・手で書いた `anchor`）は差し替える前の絵で決め、`from` の脚は書き出しの倍率の逆数で拡大縮小してから貼る。差し替えた姿勢と中割りの足元の点は、`from` の足元を写した点になる（どの姿勢でも脚が同じ大きさ・同じ位置に出る）。
- 足元と背は人物の塊だけで測る（床の薄い影は拾わない）。`from` は足元の高さを合わせ、切れ目の帯で脚の重なりが一番大きくなる位置に横へずらして（±40px まで）重ねる（`fix_x: true` ならずらさない）。
- 腿の縁に手がかかる中割りでは、手の縁が少しにじむことがある。股の分かれ目が `from` より高い絵（手を頭の上に挙げて上着が上がった伸び）は、股に細い白い筋が残る。
- 斜め・横・後ろの姿勢（`yaw` を書いた姿勢）は脚の見え方が違うので、既定では差し替えない。
- 差し替える姿勢の絵は `from` と同じ大きさ（画素数）にする。違うと止まる。

## 囲まれた白を閉じる: matte（opt-in）

透明にする処理（`lib.matte`）は、既定では顔の箱の外にある「囲まれたほぼ白」（明るさ 241 以上で、絵の縁につながっていない所）を背景にする。毛束の間や腕と体の間のすき間を抜くためだが、白いシャツ・袖口・おでこの光も透ける。明るい地に重ねる型では見えないが、暗い背景に重ねると穴に見える。

```json
"matte": {"enclosed": "keep"}
```

| 項目 | 意味 |
|---|---|
| `enclosed` | `bg`（既定・今まで）か `keep`。`keep` は囲まれた白をキャラの一部として閉じる。ただし、内側（縁を 3 画素除く）の 9 割以上が背景の色そのもの（外につながる白の中央値 ±2）の所は、透けて見えている背景として抜く（脚の間・腕と体の間・上げた手と頭の間）。白目・歯・毛束の間の小さな白の扱いは今までどおり |

- `vm render --enclosed keep|bg` で、その回だけ変えられる。書き出しは 1 割ほど遅くなる（凜の 6 秒で 72 → 78 秒）。
- 測った値（2026-11-01、凜の姿勢と Wan のコマ）: 内側の「背景の色そのもの」の割合は、シャツの本体 0.57〜0.70、袖口 0.74〜0.87、おでこの光 0（肌の色が乗る）、本物のすき間 0.96〜1.00。袖口に近い値のすき間があれば白く残るので、暗い背景で 1 コマずつ確かめる。
