# config.json（作業フォルダの設定）

```json
{
 "name": "icm-explainer", "fps": 30, "pad": 100, "home": "home", "seed": 5,
 "mascot": {"description": "a glossy resin chibi figurine girl with ... (英語。絵を描かせる時の『同じキャラ』の説明)"},
 "poses": {"home": {"desc": "hands lightly clasped in front of her waist, facing the camera almost straight on"},
           "point": {"desc": "her left arm extended toward the viewer's right with an open palm, presenting", "refs": ["gassho"]}},
 "pairs": [["home", "point"]],
 "face": {"mouth_roi": [450, 575, 600, 680], "eye_roi": [370, 500, 640, 600]},
 "floor": {"clean": true, "y0": 1180},
 "anchor": {"mode": "boot"},
 "events": [{"line": 1, "kw": "そこで", "fallback": 0.65, "pose": "point"}],
 "voice": {"caption": "...", "seed": 2024, "ref": "voice/ref.wav", "gap": 0.5, "end": 69.0,
           "candidates": ["説明文1", "説明文2"], "test_lines": [0, 3],
           "lines": [{"text": "台本どおりの文", "say": "合成に渡す文（読みを直した文）", "start": 0.0}]}
}
```

| 項目 | 意味 |
|---|---|
| `fps` | 出力のコマ数。既定30 |
| `pad` | 絵の左右に足す白い余白（画素、絵の幅 941 に対して）。体を動かしたとき指先が切れないための余裕。既定100 |
| `out_height` | 出力の高さ（既定1280）。幅は絵の縦横比と pad から決まる |
| `home` | 基本の姿勢の名前（既定は poses の最初）。軸足・口と目の範囲の基準 |
| `mascot.description` | `vm poses` が絵を描かせる時の、キャラの英語の説明。服・髪・目・台座など、同じに保ちたい特徴を書く |
| `poses.<名前>.desc` | その姿勢の英語の説明（`vm poses` が絵と中割りの指示に使う） |
| `poses.<名前>.refs` | 絵を描く時に一緒に参照させる別の姿勢（顔・服をそろえるため） |
| `pairs` | 中割りを作る姿勢の組。`[a, b]` で `ib/ib_a_b_1..5.png`。行き来のどちらの向きにも使う |
| `face.mouth_roi` / `face.eye_roi` | home の絵で測った口・目の範囲 `[x0, y0, x1, y1]`（口は差分の外側、目は両目を含む）。`vm grid` で読む |
| `floor.clean` | 足元の台座・靴の反射を消し、接地の影を足す（台座つきの絵向け）。`y0` は足元の処理を始める高さ（既定は絵の高さの70.5%） |
| `anchor.mode` | `boot`: 向かって左の黒い靴を軸足にして全部の絵でそろえる（既定）。`manual`: `points` に姿勢ごとの `[x, y]`（と `scales`）を書く。`none`: そろえない |
| `inbetween_fps` | 中割り5枚を見せる速さ（既定15 = 0.33秒） |
| `inbetween_div` | 姿勢の間を何等分するか（既定6 → 中割り5枚 `ib_<a>_<b>_<k>.png`）。12 にすると中割り11枚 `ib_<a>_<b>_<k>_12.png`。既存の5枚を偶数番（2k）に写せば、`vm poses inbetweens` は奇数番だけを「両隣のちょうど中間」として描く |
| `mouth_scale` | 口の開きの全体の倍率（既定1.0）。`--mouth-scale` でも指定できる |
| `lipsync` | 口パクの母音の決め方。`"amp"`（既定。聞き取りの語を音の数で等分）か `"mora"`（下の「口パク: mora」）。`vm render --lipsync mora` でも指定できる |
| `mora` | `lipsync: "mora"` の細かい設定（省略可）: `pause_weight`（句読点の息つぎを何モーラ分の長さにするか、既定2.0）、`close_frac`（両唇音の頭で口を閉じる割合、既定0.3）、`min_close`（閉じる最短の秒、既定0.067＝30fps の2コマ）、`trim`（行の頭と終わりの無音を声の大きさで削ってから割り付ける、既定 true） |
| `motion` | 二次運動（省略時は使わない＝今までどおり）。`true`（か `{}`）で全部既定、辞書で項目ごとに上書き。`vm render --motion on|off` でも切り替えられる。下の「二次運動」 |

**倍の細かさ**（2026-10-14、cad-viewer の解説動画で使用）: `"fps": 60, "inbetween_div": 12, "inbetween_fps": 30`。中割り11枚を0.37秒で見せ、口の形は30fpsの1コマ（2コマ）以下の揺れを消し、まばたきは段の間を溶かして十数段で閉じる。描き足した中割りは「両隣の中間」と指示しても順番を外す枚が出る（1枚目がいきなり腕を組み切る等）ので、`ib` を姿勢の行ごとに並べて見て、外れた枚は腕の位置を具体的に書いて描き直す。

## events（姿勢の切り替え）

上から順に、直前の姿勢から `pose` へ移る。**切り替えが終わる時刻**（ `line` + `kw`/`word` の場合）か、**始まる時刻**（それ以外）を指定する。

| 書き方 | 意味 |
|---|---|
| `{"line": 3, "kw": "ばねが", "pose": "gassho"}` | 行3で、声の中の「ばねが」（ひらがな、小さい「ゃゅょ」を含む語は不可）の直前に切り替えが終わる |
| `{"line": 3, "word": ["しゃ"], "pose": "open"}` | 行3で、聞き取りの語（ひらがな）が一致する最初の語の直前に終わる。小さい「ゃゅょ」を含むとき・Whisper が漢字を取り違えるときはこちら |
| `{"line_start": 5, "offset": -0.4, "pose": "point"}` | 行5の頭の0.4秒前に始まる |
| `{"line_end": 8, "offset": 0.05, "pose": "home"}` | 行8の終わりの0.05秒後に始まる |
| `{"at": 12.3, "pose": "arms"}` | 12.3秒に始まる |

- `fallback`（0〜1）: 声から見つからなかったとき、行の中のこの割合の位置とみなす（標準エラーに「推定」と出る）。
- `offset`: ± 秒で微調整する。
- pairs にない組（a→b）は、中割りなしで切り替わる。必要なら間に別の姿勢を挟む（例: open→home→arms）。

## 口パク: mora（opt-in）

`"lipsync": "mora"` にすると、口の母音を聞き取り（Whisper）ではなく**台本のかな**から決める。

1. 行ごとのかな台本: `voice.lines[].kana`（ひらがな・カタカナ・句読点）。無ければ `say`（無ければ `text`）を pykakasi でかなにしたもの。英字・数字は読まれないので、混じる行は `kana` を書く（例: 「ICM」→「あいしーえむ」）。漢字の読みを pykakasi が取り違える行も `kana` で直す。
2. 行の声の範囲: `voice/timing.json` の行の開始〜終了から、声が小さい頭と終わりを削る（`mora.trim`）。
3. その範囲をモーラの数で等分する。拗音（きゃ）は1モーラ、「っ」「ん」「ー」も1モーラ。句読点は `pause_weight` モーラ分の息つぎ（口を閉じる）。
4. 口を閉じる所: 「っ」、息つぎ、両唇音（ま・ば・ぱ行）の頭（`close_frac`）、両唇音の前の「ん」（「さんぽ」）。
5. 開きの大きさは今までどおり声の大きさで決める（`choose_mouth`）。声が小さいコマは閉じる。

`events`（姿勢の切り替え）は今までどおり聞き取りの時刻を使う。既定（`amp`）の動きは変わらない。

## voice

- `lines[].text` は字幕・一致の判定に使う台本、`say` は合成に渡す文（読みが割れる語だけひらがなにする）。`start` を書くと、その秒に行を置く（主動画の流れに合わせたいとき）。省略すると前の行の後ろに `gap` 秒あけて続ける。
- `ref` を書くと全行をその声で読む。省略すると、最初に作った行が残りの手本になる。
- `end`: 全体の長さ（省略時は最後の行の終わり＋0.6秒）。主動画の長さに合わせたいとき書く。
- 説明文（`caption`）は声の人物像と話し方を書く（例: 余裕のある大人の女性。艶のある低めの声。…てきぱきと早めに説明している。クリアな音質）。「テンポよく」「てきぱき」で速さを、「近い距離感」で距離感を、絵文字（台詞の語尾に 😏 など）で口調を足せるが、絵文字は暴れやすい。

## 二次運動: motion（opt-in）

`"motion": true`（か `vm render --motion on`）で、体の小さな動きを足す。書かなければ今までどおり（正弦の息づかいと、2.6〜4.6 秒の一様な間隔のまばたき）。

```json
"motion": {
  "breath": {"period": 3.6, "jitter": 0.12, "inhale": 0.4, "scale": 0.004, "lift": 2.0},
  "body":   {"sway": 1.5, "period": 5.3},
  "head":   {"roll": 0.8, "period": 4.1, "nod": 2.0, "neck": 0.6, "radius": 0.9},
  "blink":  {"mean": 3.4, "spread": 0.35, "min": 1.6, "max": 7.0, "double": 0.15, "on_switch": true},
  "switch": {"ease": "in_out", "anticipate": 0.15, "anticipate_px": 5, "overshoot_px": 4, "settle": 0.45}
}
```

値は上が既定。書いた項目だけ上書きされ、項目を `false` にするとその動きだけ止まる（例: `"motion": {"head": false}`。`"blink": false` はまばたきをしない）。知らない項目名はエラーで止まる。画素は姿勢の絵の画素（`out_height` に縮める前）。

| 項目 | 動き |
|---|---|
| `breath` | 呼吸。周期 `period` 秒が ±`jitter` の割合でゆっくりゆらぐ。1回のうち `inhale` の割合で吸い、残りでゆっくり吐く。足元を中心に `scale` の割合で伸び縮みし、`lift` 画素持ち上がる |
| `body` | 体の左右の揺れ（`sway` 画素）。割り切れない周波数の正弦を重ねたゆらぎで、同じ動きをくり返さない |
| `head` | 首から上だけを傾ける（`roll` 度）。声の出だしで `nod` 画素うなずく。首の位置は `face.mouth_roi`・`eye_roi` から見積もる（口の下端から「目→口」の距離の `neck` 倍下、頭の半幅は目の範囲の幅の `radius` 倍）。首より下（肩・腕）は動かさない |
| `blink` | まばたきの間隔を対数正規でゆらがせる（中央値 `mean` 秒、ばらつき `spread`、`min`〜`max` 秒に切る）。`double` の割合で2回続け、`on_switch` なら姿勢の切り替えの頭でもまばたく |
| `switch` | 姿勢の切り替え。中割りを何枚目まで進めるかを `ease`（`linear`・`in`・`out`・`in_out`・`sine`）で決める（長さは今までどおり）。切り替えの `anticipate` 秒前から `anticipate_px` 画素沈み（予備動作）、終わってから `settle` 秒、上へ `overshoot_px` 画素行き過ぎて戻る（オーバーシュート） |

ゆらぎは `seed` で決まる（同じ config なら毎回同じ動き）。まず `vm render <作業フォルダ> --motion on --mode white --from 0 --to 10` で今までの動きと見比べる。首の位置がずれて肩が引っぱられるときは `head.neck` を小さく、頭の端が残るときは `head.radius` を大きくする。

## 向きと視線（opt-in）

顔を横に向ける・体ごと斜めや横を向く・視線を動かす。絵の描き方と名前の決まりは `docs/mascot-views-spec.md`（リポの docs）。下のどれも、書かなければ今までどおり。

```json
"poses": {
  "turn_l": {"desc": "...", "refs": ["home"], "yaw": -40,
             "face": {"mouth_roi": [400, 575, 540, 680], "eye_roi": [330, 500, 590, 600]}, "anchor": [430, 1250]},
  "back":   {"desc": "...", "yaw": 180, "face": false}
},
"transition": {"mode": "fade", "dur": 0.25, "squash": 0.06},
"events": [{"line": 2, "kw": "こちら", "pose": "turn_l", "via": "turn"}],
"gaze": {"lead": 0.15, "hold": 1.0, "events": [{"line": 3, "kw": "ここ", "look": "l", "hold": 1.2}, {"at": 20.0, "look": "u", "until": 21.5}]}
```

| 項目 | 意味 |
|---|---|
| `poses.<名前>.yaw` | 体の向き（度。画面の左が負、正面 0、真横 ±90、後ろ 180）。目安でよい |
| `poses.<名前>.head_yaw` | 顔の向き（無ければ `yaw`）。視線の部品の選び方と、視線の先回りに使う |
| `poses.<名前>.face` | その姿勢で測った口と目の範囲（`face` と同じ書き方）。斜め・横の顔は `home` からの自動の写しが合わないので書く。`false` は顔が見えない姿勢（後ろ向き）: 口・目・視線の部品を作らず、貼らない |
| `poses.<名前>.anchor` | その姿勢の足元の基準点 `[x, y]`。`anchor.mode` が `boot` でも、書いた姿勢はこちらを使う（靴で揃わない姿勢用）。`manual` で `points` に無い姿勢にも使う |
| `transition` | 中割りの無い組の切り替えのつなぎ。`mode`: `cut`（一瞬。`kw` / `word` では語の 0.04 秒前に切り替える。書かない時は中割りの長さだけ早く切り替わる）・`fade`（`dur` 秒で溶かす）・`turn`（溶かしながら、途中で横に最大 `squash` の割合だけ縮めて回ったように見せる）。中割りがある組は今までどおり中割り |
| `events[].via` | その切り替えだけのつなぎ（`cut`・`fade`・`turn`）。中割りがある組でも `via` が優先。`transition` が無ければ長さと縮みは上の既定 |
| `gaze` | 視線を使う。`vm poses parts` が視線の部品も描くようになる（顔が正面の姿勢は `g_l` `g_r` `g_u`、斜めは `g_c` `g_u`、横・後ろは無し） |
| `gaze.events` | 黒目を動かす所。`look`: `c`（見る人）・`l`（画面の左）・`r`（画面の右）・`u`（上）。開始は `events` と同じ書き方（`kw` / `word` はその語の声の時刻から。`offset` はどの書き方にも足す。`at` にも）。終わりは `until`（秒）か開始から `hold` 秒 |
| `gaze.lead` | 顔の向き（`head_yaw`）が変わる切り替えの、この秒数前から切り替えの終わりまで、目が先に新しい向きへ動く（`0` で切る）。`gaze.events` の指定が優先 |

- `kw` / `word` の切り替えは「その語の直前に終わる」ので、つなぎが `fade`・`turn` の時は中割りの長さの代わりに `dur` を引いて始める。`cut`（`via` でも `transition.mode` でも）は長さ 0 として語の 0.04 秒前に切り替え、二次運動の予備動作・オーバーシュートと視線の先回りも長さ 0 で計る。
- 視線の部品が無い姿勢では、目は元の絵のまま。まばたきの間は視線の部品を貼らない。斜めの顔で `l`（向いている側）を指定すると元の目（もうそちらを見ている）、反対側や `c` は `g_c`（見る人の方へ戻す）。
- 二次運動（`motion`）とは両立する。首の傾きの中心は、その姿勢の `face` から見積もる。溶かしている間は両方の絵をそれぞれ傾けてから溶かす。
- 向きの違う姿勢（`yaw`・`head_yaw`・`face`・`anchor` のどれかを書いた姿勢）の絵が `home` と違う大きさだと止まる。
