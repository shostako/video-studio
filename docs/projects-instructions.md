# Projects の指示文（Project instructions の原本）

claude.ai の Project settings > Memory > Project instructions に貼る文面。変えたらここも直す。

```
このプロジェクトは shostako/video-studio（public）の開発。仕事で使う解説動画・まとめ動画を、動画生成サービスに頼らず手元で作るスキル（video-scene / video-mascot）の品質を上げる。

- 最初に CLAUDE.md、ROADMAP.md、DECISIONS.md、docs/handoff-2026-10-15.md を読む。
- やるのは ROADMAP.md の「クラウドのスレッドがやること」を上から順に1つずつ。「手元待ち」には手を出さない。
- 毎回 main から枝を切って PR を出す。`python3 scripts/pr_gate.py <PR番号>` が OK を返したときに限り、門が表示する `--match-head-commit` 付きのコマンドで自分でマージしてよい（ci 緑＋先頭コミットへの Codex レビュー完了＋未解決の指摘なし。詳細は CLAUDE.md）。指摘を直して push したら `@codex review` で再レビューを頼む（Codex は push では再レビューしない）。マージしたら ROADMAP.md の「済んだこと」と logs/ を更新する。
- 既定の挙動は変えない。新しい機能は opt-in で足す。既定を切り替えたくなったら DECISIONS.md の「未決」に書いて止まる。
- 声の良し悪し・絵の見た目はあなたには判定できない。判定が要る所は「手元待ち」に書いて止まる。
- 実物の絵・声・動画・顧客名は入れない。テスト用の素材は合成する。
- 判断に迷ったら推測で進めず DECISIONS.md の「未決」に書いて止まる。
```

## 放置で進めるときに会話へ送る文（コーディネーター用）

プロジェクトの会話（左の欄）は、頼まれた分だけスレッドを起こして止まる。続けて進めさせるには、次の文を一度送る。Claude が project memory に保存して、以後の判断に使う。

```
ROADMAP.md の「クラウドのスレッドがやること」を、未着手の分を上から順に、確認を取らずに自動で進めて。
- スレッドは同時に最大2つ。同じファイルを触る項目は並走させず、順に。
- 1つマージされたら、次の項目のスレッドを自分で起こす。私に聞かない。
- 止まるのは、(a) DECISIONS.md の「未決」に書いて止まったスレッドが出たとき、(b) 「手元待ち」が要るとき、(c) 全項目が終わったとき。
- 更新は、完了したときと止まったときだけ短く。
```
